# 전국 제조기업 지도

대한민국의 민간 제조·생산·발전·저유·물류 관련 사업장을 **실제 지역 생산거점 단위**로 정리·검증하는 데이터 프로젝트입니다.

## 현재 데이터

- 최신 데이터: `manufacturing_sites_latest.csv`
- 기준일: 2026-09-07
- 사업장 행 수: 1,871
- 포함 시·도: 15개
- 주요 컬럼: 시·도, 시·군, 기업명, 업종, 생산품, 매출액, 기업규모, 외투기업, 회계기준, 출처URL, 홈페이지URL, 비고

## 핵심 검증 원칙

1. 공기업·공공기관은 제외하고 민간기업만 등록합니다.
2. 법인 본점이 아니라 해당 지역에서 실제 운영 중인 공장·생산거점을 확인합니다.
3. 폐쇄·이전·매각·생산중단·합병·사명변경·사업양수도·분할 여부를 교차검증합니다.
4. 같은 법인이라도 서로 다른 지역에 실제 생산거점이 있으면 사업장별 별도 행으로 관리합니다.
5. 합병·사명변경은 동일 법인 또는 승계법인 여부를 확인해 중복 등록하지 않습니다.
6. 일반 작업은 연매출 800억원 이상을 기본으로 하며, 지역별 별도 기준이 있는 경우 해당 기준을 적용합니다.
7. 기업명은 LG화학, GS칼텍스처럼 영문 이니셜·브랜드 약칭만 영어로 두고 나머지는 한글 표기를 우선합니다.

## 출처 우선순위

금융감독원 DART 공시·감사보고서·사업보고서, 기업 공식 홈페이지·공식자료, 지자체·산업단지 자료, 최근 채용·사업장 안내, 신뢰할 수 있는 언론자료 순으로 검증합니다. 중요한 상태 변경은 가능한 한 공식자료로 교차검증합니다.
